# akse-elite

Premium Nuxt 4 website for akse, focused on cinematic digital heritage experiences.

## Package Manager

This project uses **pnpm only**.

## Setup

Install dependencies:

```bash
pnpm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
pnpm dev
```

## Production

Build for production:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```
